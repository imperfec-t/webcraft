Design, build and ship websites with your AI agent, measured, not guessed.

webcraft gives coding agents expert website skills, then backs them with real checks: contrast-solved color systems, a pre-launch audit, a library of design references and ready-to-fill build prompts.

How it works

One engine, four ways in. Every surface calls the same code, so results always match.

1 · Skills teachTen instruction files tell your agent how experts plan a homepage, pick colors, animate, and run QA. Installed once per agent.
2 · Tools measureThe engine does the parts an AI gets wrong: contrast math, markup audits, stack fingerprints, file paths.
3 · Libraries inspire84 DESIGN.md references and 13 build prompts give a starting direction, plus your own private prompts.
4 · Same results everywhereClick it here, type it in a terminal, or let the agent call it over MCP. It is one engine.

A typical project

Follow the stages in order; each ends with its own check.

PlanSection order from the visitor's questions (homepage-blueprint skill).
LookGenerate tokens from a brand color, or pick a reference design.
BuildFill a prompt and let your agent build with the skills installed.
CheckContrast and a launch audit: blockers first, with fixes.
ShipHand off with the verdict and what still needs real content.

What happens when you ask your agent

With the skills installed and the MCP server connected.

Claude Code · bakery-site
Build a homepage for my bakery "Crumb & Co" in a calm style like Linear, warm orange brand color.
I'll plan the sections first, then base the visual system on Linear's design language with your color.
skill · homepage-blueprint, design-md
get_design("linear.app", check) 1 pair below AA
generate_tokens("#e8732a", editorial) all pass
Built 8 sections with tokens.css. Kept Linear's density and hairlines, not its name, logo or fonts.
audit_site("./dist") Ready · 0 blockers
1
The agent picks skills by descriptionOnly skill descriptions sit in its context. "Homepage" and "like Linear" match homepage-blueprint and design-md, so it reads those in full.
2
It calls webcraft for factsget_design returns Linear's palette, type and spacing, and flags a contrast problem in the original so it isn't copied.
3
Your brand replaces theirsgenerate_tokens builds a full light and dark system from your orange, with every text pair solved to pass WCAG AA.
4
It checks before saying "done"audit_site runs about 40 launch checks on the build. Blockers get fixed and anything it can't verify is listed for you.
