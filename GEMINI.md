# webcraft

For website planning, design, build or QA work, use the webcraft skills in `skills/`. Read the matching `SKILL.md` first, and use `website-workflow` when the task spans several stages.

When the webcraft MCP server is connected, use its tools for anything measurable: `generate_tokens` for palettes, `check_contrast` for color pairs, `audit_site` before launch, and `detect_stack` / `teardown_site` to analyze a reference site. Report what the tools could not check instead of assuming it passed.
